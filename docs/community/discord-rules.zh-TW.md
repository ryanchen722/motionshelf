# Motion House 社群規則（Discord 草稿）

歡迎來到 MotionShelf 動態小屋社群！這裡讓大家分享自己做的動態效果、互相交流、回報問題。
請先花一分鐘讀完規則。進到伺服器就代表你同意遵守。

## 建議的頻道

| 頻道 | 用途 |
|---|---|
| #公告 | 版本更新、重要通知（只有管理員能發言） |
| #規則 | 這份規則 |
| #自我介紹 | 打聲招呼 |
| #效果分享 | 分享你做的 `.mseffect`，要附預覽（見下方格式） |
| #作品展示 | 分享用 MotionShelf 輸出的影片成品 |
| #問題求助 | 安裝、使用上的問題 |
| #回報問題 | 發現 bug，請附步驟和環境 |
| #功能建議 | 想要的新功能 |
| #閒聊 | 其他話題 |

## 一、基本禮儀

1. 互相尊重。不人身攻擊、不歧視、不騷擾、不貼仇恨或色情暴力內容。
2. 討論請留在對應的頻道，同一個問題不要重複貼在好幾個頻道。
3. 不要發廣告、推銷、拉人入群或邀請連結，除非管理員同意。
4. 不要公開別人的個人資料（真實姓名、住址、電話、Email 等）。
5. 請使用繁體中文或英文，方便大家一起讀。

## 二、分享效果的規則

效果是會執行的網頁程式碼，所以分享前後都要特別小心。

**分享的人要做到：**

1. 貼文要附：效果名稱、一張截圖或一段短影片、簡短說明（能調哪些參數、適合怎麼用）。
2. 標明授權：可以直接用、可以修改、可以商用，還是「僅限個人使用」。不確定就寫「僅供個人使用，請勿再散布」。
3. 只分享你自己做的，或你有權分享的作品。不得上傳：
   - 別人的作品、付費素材、商業字型或品牌標誌；
   - 盜用或抄襲他人效果而不註明來源。
4. 不得夾帶惡意內容：不能偷偷連網、竊取資料、載入外部程式碼、讀寫 cookie 或瀏覽器儲存空間，或做任何誤導使用者的行為。違反的人會被永久移出伺服器。
5. 效果裡有用到 Three.js 等函式庫時，請保留它原本的授權標頭，不要刪掉。

**下載的人要做到：**

1. **只匯入你信任的人分享的效果。** MotionShelf 匯入前會自動檢查，但檢查不能保證 100% 安全。
2. 匯入時如果跳出警告（連網、`eval`、外部網址、外部 script 等），請讀清楚再決定，不確定就不要匯入。
3. 想改別人的效果前，先確認作者有沒有允許修改，並依授權標示來源。
4. 發現可疑的效果，請私訊管理員，不要在公開頻道散布。

## 三、關於贊助

- MotionShelf 是免費開源的，**使用不需要付費，也不會因為沒贊助而被區別對待**。
- 如果你喜歡這個專案，歡迎自由贊助，金額隨意，謝謝！
- 請不要在社群裡向其他成員募款或私下要求贊助。

## 四、問題回報的方式

提問或回報問題時，請附上：

- MotionShelf 版本（或 GitHub 的提交編號）、macOS 版本；
- 你做了什麼、預期會怎樣、實際怎樣；
- 截圖或錄影（如果可以）；
- 如果是效果的問題，附上效果檔，並先確認它是否可信。

不要貼 API 金鑰、密碼、登入資訊，包含 AI 服務的金鑰。

## 五、違規處理

1. 輕微：管理員提醒。
2. 重複或較嚴重：禁言或刪除內容。
3. 惡意效果、盜用、詐騙、騷擾：直接永久移出，必要時向平台舉報。

管理員保有最終解釋權。如果你覺得處理有誤，可以私訊管理員申訴。

## 六、免責聲明

社群成員分享的效果和內容，由分享者自行負責，不代表 MotionShelf 專案或管理員的意見，也不保證可用或安全。使用前請自行判斷風險。
